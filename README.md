# 격투왕 3D

Three.js로 만든 2인용 3D 격투 게임.

- 로컬 대전 : 한 키보드로 둘이 대전
- 온라인 대전 : 방장이 중계 서버를 켜면, 서버 창에 나온 링크(또는 이 페이지 주소 뒤에 `?server=서버주소`)로 들어와 빠른 매칭 · 방 코드로 대전
